# Priority Queue (Java)

Based on section 2.4 ("Priority Queues") of *Algorithms*, 4th edition, by Robert Sedgewick and Kevin Wayne, Lecture 8 ("Binary Heaps") of MIT 6.006 *Introduction to Algorithms*, and the Generics lesson of *The Java Tutorials*.

A generic binary min-heap in an array, ordered by any `Comparator`: sift-up and sift-down, linear-time construction measured by counting comparisons, a fail-fast iterator, and two uses of the heap, heapsort and top-k over a stream. It covers bounded type parameters and wildcards, and building and testing with Maven and JUnit.
