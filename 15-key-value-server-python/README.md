# Key-Value Server (Python)

Based on chapters 3 ("TCP"), 5 ("Network Data and Network Errors") and 7 ("Server Architecture") of *Foundations of Python Network Programming*, 3rd edition, by Brandon Rhodes and John Goerzen, and the Web Server assignment from chapter 2 of *Computer Networking: A Top-Down Approach* by James Kurose and Keith Ross.

An in-memory key-value database served over TCP with its own protocol, built directly on sockets. It covers message framing, protocol design, threaded and asyncio servers, network failures, and a hand-written HTTP interface.

The full task is in [ASSIGNMENT.md](ASSIGNMENT.md).
