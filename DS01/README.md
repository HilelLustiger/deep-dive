# Linked List (C++)

Based on Lecture 2 ("Data Structures") of MIT 6.006 *Introduction to Algorithms*, chapter 3 ("Linked Lists") of *Open Data Structures* by Pat Morin, and the chapters of [Learn C++](https://www.learncpp.com/) on pointers, classes and dynamic memory.

A singly linked list of integers with head and tail pointers, built with raw pointers and `new`/`delete`. It covers ownership and destructors, deleted copy operations, exceptions and `std::optional`, in-place reversal, and finding memory bugs with sanitizers and a leak checker and logic bugs with a model test. It starts from the [TOOL01](../TOOL01/) template.

The full task is in [ASSIGNMENT.md](ASSIGNMENT.md).
