# Binary Search Tree (TypeScript)

Based on sections 3.1 ("Symbol Tables") and 3.2 ("Binary Search Trees") of *Algorithms*, 4th edition, by Robert Sedgewick and Kevin Wayne, the matching module of Princeton's *Algorithms, Part I*, and Lecture 6 of MIT 6.006 *Introduction to Algorithms*.

A generic ordered symbol table built on an unbalanced binary search tree, with keys ordered by a comparator function. It covers recursive tree updates, subtree sizes, floor and ceiling, rank and select, range queries, in-order iteration with generators, Hibbard deletion, and how insertion order decides the tree's height.
